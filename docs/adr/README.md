# Architecture Decision Records

We record significant architecture decisions as short documents, following
[Michael Nygard's format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

To propose a decision, copy `template.md` to `NNNN-short-title.md` and open a pull request.
Accepted ADRs are never edited. When a decision changes, a new ADR supersedes the old one.
