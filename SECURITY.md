# Security Policy

## Supported versions

obsrv is in early development. Only the latest commit on `main` receives security fixes until v1.0.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Instead, report them privately through [GitHub private vulnerability reporting](https://github.com/mtk14n/obsrv/security/advisories/new).

Please include the following:

- a description of the issue and its impact;
- the steps to reproduce it, or a proof of concept;
- the affected version or commit.

We aim to acknowledge reports within 3 business days and to keep you informed until a fix is released.
We are happy to credit reporters in the advisory if they wish.
